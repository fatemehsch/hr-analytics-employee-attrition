# HR Analytics: Employee Attrition & Wellbeing Analysis

## 📌 Project Overview

An end-to-end data analytics project focused on understanding employee attrition and wellbeing in the tech industry. This project covers the full data pipeline: from raw messy data to a clean, analyzed, and visualized dashboard.

The goal is to uncover insights that help HR teams make data-driven decisions about retention and employee wellbeing.

## 🎯 Objectives

- Identify the main factors behind employee attrition
- Analyze the relationship between mental health and work environment
- Build a clean and reusable data pipeline
- Deliver an interactive Power BI dashboard for HR stakeholders

## 🛠️ Tech Stack

| Tool | Purpose |
|------|---------|
| Python (pandas, numpy, matplotlib, seaborn) | Data cleaning & EDA |
| MySQL | Data storage & SQL analysis |
| Power BI | Interactive dashboard |
| Git & GitHub | Version control |

## 📊 Data Source

- OSMI Mental Health in Tech Survey (Open Sourcing Mental Illness)
- Source: [Kaggle - OSMI Mental Health in Tech Survey](https://www.kaggle.com/datasets/osmi/mental-health-in-tech-survey)
- The dataset is intentionally messy with missing values, inconsistent formats, and text fields — perfect for demonstrating real-world data cleaning skills.
